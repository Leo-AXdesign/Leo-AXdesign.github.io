클로드 스킬

클로드 코드에 일하는 방법을 더하는 설명서

스킬은 클로드 코드에게 특정한 일을 하는 방법을 적어 준 설명서입니다. 폴더 하나에 SKILL.md 파일이 들어 있고, 클로드는 맡은 일이 그 설명과 맞을 때 꺼내 읽고 그대로 따릅니다. 한 번 설치해 두면 같은 부탁을 할 때마다 같은 방식으로 일합니다.

이 사이트도 클로드 코드로 만들고 있고, 디자인 작업에 쓸 만한 스킬을 찾다가 이 페이지를 정리했습니다. 설치 수는 2026년 11월 4일에 skills.sh에서 확인한 숫자입니다.

스킬을 찾아 주는 스킬부터

공개된 스킬은 수십만 개가 넘어서 직접 검색해 고르는 것부터 일입니다. find-skills는 그 검색을 클로드가 대신 하게 만드는 스킬입니다. Next.js를 만든 회사 버셀(Vercel)의 실험용 저장소 vercel-labs에 들어 있고, 무료입니다(MIT).

스킬 안에 적힌 순서는 이렇습니다.

  1. 무슨 일을 하려는지 파악합니다.
  2. skills.sh 순위에서 설치 수가 많은 스킬이 있는지 먼저 봅니다.
  3. 없으면 npx skills find 검색어로 찾습니다.
  4. 설치 수 1천 이상, 공식 출처(vercel-labs, anthropics, microsoft 등), 저장소 별 100개 이상인지 확인합니다.
  5. 후보를 이름·설치 수·출처·설치 명령과 함께 보여 줍니다.
  6. "설치해 줘"라고 하면 설치합니다.

설치

터미널에 아래 한 줄을 붙여 넣습니다. Node.js가 설치돼 있어야 합니다.

npx skills add vercel-labs/skills --skill find-skills -g -a claude-code -y
  • -g: 어느 폴더에서 클로드 코드를 열어도 쓰이게 전역으로 설치합니다(~/.claude/skills). 빼면 지금 폴더에만 설치됩니다.
  • -a claude-code: 클로드 코드에 설치합니다. 코덱스는 -a codex, 커서는 -a cursor입니다.
  • -y: 확인 질문을 건너뜁니다.

설치한 뒤에는 클로드 코드를 새로 열어야 목록에 나타납니다. 스킬은 세션을 시작할 때 읽기 때문입니다. 클로드 앱의 채팅 창이 아니라 클로드 코드(터미널·데스크톱 앱의 Code 탭)에서 쓰는 방법입니다.

이렇게 물어보면 됩니다

평소 말투로 부탁하면 됩니다. 고르는 기준을 같이 말하면 결과가 더 좁혀집니다.

  • 피그마 시안을 코드로 옮기는 스킬 찾아 줘
  • 이 사이트 주소에서 색이랑 글꼴 값을 뽑아 주는 스킬 있어?
  • 웹 접근성 점검하는 스킬 찾아 줘. 설치 수 1만 이상만
  • 포스터 한 장 만드는 스킬 있어?
  • 발표 자료(PPT) 만드는 스킬 찾아서 설치까지 해 줘
  • 테일윈드로 디자인 시스템 잡는 스킬 후보 3개 비교해 줘
  • 버튼 눌렀을 때 움직임이 어색한지 봐 주는 스킬 있어?
  • 리모션으로 짧은 소개 영상 만드는 스킬 찾아 줘

검색과 AI 답변에 잡히게 하는 스킬 (SEO·AEO·GEO)

AI로 포트폴리오나 랜딩 페이지를 만드는 건 금방인데, 만든 다음에는 찾아오는 사람이 없습니다. 구글에 검색해도 안 나오고, 챗GPT에 물어봐도 내 사이트는 답에 없습니다. 요즘은 이 문제를 세 갈래로 나눠 부릅니다.

  • SEO: 검색 결과에서 위에 나오게 합니다.
  • AEO(답변 엔진 최적화): AI 답변이나 구글 AI 개요에 내 문장이 그대로 뽑히게 합니다.
  • GEO(생성형 엔진 최적화): 챗GPT, 퍼플렉시티 같은 생성형 AI가 내 사이트를 출처로 달게 합니다.

사이트 폴더에서 클로드 코드를 열고 이런 스킬을 깔아 두면, "검색이랑 AI 답변에 잘 걸리게 봐 줘" 한마디로 고칠 목록이 나옵니다. 터미널에서 npx skills find seo로 찾으면 아래처럼 설치 수와 함께 나옵니다.

설치 수가 많은 것 가운데 쓰임새가 겹치지 않게 다섯 개를 골랐습니다.

하나만 깐다면 설치 수가 가장 많은 seo-audit부터 보면 됩니다. 스킬 페이지 오른쪽에 설치 수, 깃허브 별, 보안 점검 결과가 있습니다. seo-audit은 세 점검 중 Snyk이 '주의(WARN)'로 떠 있습니다. 주의가 하나라도 있으면 설치한 뒤 SKILL.md를 열어 무엇을 시키는지 직접 확인하는 편이 좋습니다.

npx skills add coreyhaines31/marketingskills --skill seo-audit -g

설치한 뒤에는 이렇게 부탁하면 됩니다.

  • 이 사이트 SEO 점검해 줘. 급한 것부터
  • 챗GPT나 퍼플렉시티가 이 페이지를 출처로 쓰기 좋은지 봐 줘
  • robots.txt에서 AI 봇을 막고 있는지 확인해 줘
  • 포트폴리오 페이지마다 제목이랑 설명 태그 다시 써 줘

이름에 seo, aeo, geo가 다 들어간 스킬도 많지만 설치 수가 수백 회인 것이 대부분입니다. 이름보다 설치 수와 만든 곳을 먼저 봅니다. 그리고 어떤 스킬도 순위나 AI 인용을 보장하지는 않습니다. 놓친 기본기를 찾아 주는 점검표에 가깝습니다.

설치 전에 볼 것

스킬은 클로드에게 주는 지시문이라, 설치하면 클로드가 가진 권한 그대로 그 지시를 따릅니다. 파일을 지우거나 외부로 보내라고 적혀 있어도 따를 수 있다는 뜻입니다. 그래서 아래를 확인하고 설치합니다.

  • 설치 수가 100 아래인 스킬은 특히 조심합니다. 같은 이름을 베낀 저장소가 많습니다.
  • 만든 곳을 봅니다. 앤트로픽, 피그마, 리모션처럼 도구를 만든 회사가 직접 올린 스킬이 가장 안전합니다.
  • 설치할 때 나오는 보안 점검(Gen, Socket, Snyk)을 읽습니다. 위험 표시가 있으면 이유를 확인합니다.
  • 설치한 뒤 SKILL.md를 한 번 열어 봅니다. 긴 글이 아니라 몇 분이면 읽습니다.

자주 쓰는 명령

  • npx skills list: 설치된 스킬 보기
  • npx skills update: 설치된 스킬을 최신으로
  • npx skills remove 이름: 스킬 지우기
  • npx skills init 이름: 내 스킬 만들기 (자주 하는 작업이 있다면)
