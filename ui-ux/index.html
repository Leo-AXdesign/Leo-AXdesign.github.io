앱·웹 화면, 유저 플로우, 랜딩페이지 인스피레이션

실제 앱·웹 화면과 유저 플로우, 랜딩페이지를 볼 수 있는 UI/UX 레퍼런스 사이트를 모았습니다.

앱 화면 · 플로우 11

  • 유아이볼 (UIBowl)uibowl.io

    국내 앱·웹 화면을 로그인·결제·마이페이지 같은 UI 패턴과 업종별로 모은 레퍼런스. MAU 필터와 피그마 내보내기를 지원합니다.

  • What Was ITwwit.design

    국내 모바일 앱의 화면을 업종별·화면 패턴별·컴포넌트별로 모은 한국어 UI/UX 레퍼런스. 온보딩, 로그인, 결제 같은 화면을 앱마다 볼 수 있습니다.

  • Mobbinmobbin.com

    실제 서비스 앱·웹 화면과 플로우를 통째로 모아둔 UI 아카이브. 화면 단위 검색이 강력합니다.

  • Referorefero.design

    실제 프로덕트의 UI 패턴을 컴포넌트·페이지 유형별로 검색할 수 있는 레퍼런스 툴.

  • Page Flowspageflows.com

    온보딩, 결제 등 유저 플로우를 영상으로 기록해 둔 사이트.

  • UX Archiveuxarchive.com

    모바일 앱 유저 플로우를 단계별 스크린샷으로 정리.

  • Pttrnspttrns.com

    모바일 앱 UI 패턴 레퍼런스의 고전.

  • ScreensDesignscreensdesign.com

    앱스토어 스크린샷과 실제 앱 UI 플로우를 모아둔 사이트.

  • Nicelydonenicelydone.club

    SaaS 프로덕트의 UI 패턴·플로우를 모아둔 레퍼런스.

  • Really Good UXgoodux.appcues.com

    온보딩·엠프티 스테이트 등 잘 만든 UX 사례 모음.

  • Collect UIcollectui.com

    Dribbble 샷을 UI 요소(로그인, 404, 대시보드 등)별로 분류한 갤러리.

웹 · 랜딩 12

  • Nooknook.ai.kr

    국내·해외 웹사이트를 화장품·패션·IT 같은 업종과 쇼핑몰·랜딩 같은 목적별로 모은 레퍼런스. 색상·국가 필터와 북마크·팀 폴더가 있습니다.

  • Land-bookland-book.com

    랜딩페이지 갤러리. 산업·스타일·컬러별 필터가 잘 되어 있습니다.

  • Lapa Ninjalapa.ninja

    랜딩페이지 인스피레이션 모음. 무료 UI 킷·북도 함께 제공합니다.

  • SaaS Landing Pagesaaslandingpage.com

    SaaS 랜딩페이지 예시를 섹션·유형별로 정리한 사이트.

  • Supaherosupahero.io

    웹사이트 첫 화면(히어로 섹션)만 골라 모은 갤러리. 랜딩페이지의 첫인상을 잡을 때 좋습니다.

  • One Page Loveonepagelove.com

    원페이지 웹사이트 갤러리와 템플릿.

  • Landingfoliolandingfolio.com

    랜딩페이지·컴포넌트 인스피레이션. 섹션별 검색.

  • Minimal Galleryminimal.gallery

    미니멀한 웹사이트만 모아둔 갤러리.

  • Dark Mode Designdarkmodedesign.com

    다크 모드 웹사이트 레퍼런스만 모아둔 사이트.

  • Httpsterhttpster.net

    트렌디하고 실험적인 웹사이트를 모아둔 갤러리.

  • Curated Designcurated.design

    트렌디한 웹 디자인 큐레이션. 타입·스타일별 필터 제공.

  • Muzlimuz.li

    디자인 인스피레이션 피드. 크롬 확장 프로그램으로 새 탭에서 바로 볼 수 있습니다.

어워드 · 큐레이션 7

  • 지디웹 (GDWEB)gdweb.co.kr

    국내 웹·앱 디자인 어워드. 한국 기업 사이트 레퍼런스를 찾을 때 유용합니다.

  • 디비컷 (DBCUT)dbcut.com

    국내 웹디자인 레퍼런스 모음. 업종별·스타일별로 한국 사이트를 살펴볼 수 있습니다.

  • Awwwardsawwwards.com

    세계적인 웹 디자인 어워드. 인터랙션이 뛰어난 사이트를 매일 선정합니다.

  • CSS Design Awardscssdesignawards.com

    Awwwards와 함께 대표적인 웹 디자인 어워드.

  • FWAthefwa.com

    2000년부터 이어진 인터랙티브 웹 어워드.

  • Recent (구 Godly)recent.design

    감각적인 웹사이트만 엄선한 큐레이션. Godly에서 이름을 바꿨습니다.

  • Siteinspiresiteinspire.com

    깔끔하고 세련된 웹사이트 쇼케이스. 스타일·타입·주제별 필터 제공.

  • Bento Gridsbentogrids.com

  • Growth.designgrowth.design

관련 읽을거리

4

이 분야를 다룬 글

2026. 10. 23 문구 세 군데 고치려고 웹플로를 열었다 닫았다 할 때, 제미나이에 붙은 Webflow 연결에서 확인할 것

Webflow가 10월 15일 Google Gemini 앱의 연결 앱이 됐다. 채팅에서 페이지 제작, CMS 정리, 사이트 감사, 성과 질문을 할 수 있다고 한다. 설치는 무료이고 지금은 Webflow AI 크레딧을 쓰지 않는다. 보도자료와 마켓플레이스 페이지로 확인한 내용과 아직 알 수 없는 부분을 정리했다.

 AI 디자인 · 5분 2026. 10. 22 화면은 다 됐는데 저장 버튼이 아무것도 저장하지 않을 때, 피그마 메이크에 붙은 Payload에서 확인할 것

Figma가 10월 15일 오픈소스 CMS Payload를 Figma Make에 넣었다. 프롬프트로 앱을 만들면 데이터베이스, 파일 저장, 사용자 로그인, 관리자 화면이 같이 생긴다. 공식 블로그로 확인한 내용, 호스팅 베타·가격 미정, 아직 밝혀지지 않은 부분을 정리했다.

 AI 디자인 · 5분 2026. 10. 20 시안을 눌러 보면 안 눌릴 때, 피그마 '코드 레이어'로 확인할 것 (유료 플랜 11월 4일까지 무료)

피그마가 10월 15일 코드 레이어를 오픈 베타로 열었다. 디자인 프레임, 깃허브 저장소, 웹사이트 캡처, 프롬프트로 눌러 볼 수 있는 프로토타입을 캔버스 위에 만든다. 공식 릴리스 노트·도움말·블로그로 확인된 것과 비어 있는 것을 정리했다.

 AI 디자인 · 6분 2026. 10. 19 AI가 만든 화면이 다 똑같이 보일 때, 러버블은 '디자인 방향 3안'을 빼고 디자인 시스템을 앞세웠다

러버블이 첫 빌드 전의 디자인 방향 세 가지 선택 단계를 없앴고, 디자인 시스템은 모든 유료 플랜에서 쓸 수 있다. 공식 변경 기록과 문서로 무엇이 확인되고 무엇이 비어 있는지, 내 규칙을 한 번 정해 두는 법을 정리했다.
